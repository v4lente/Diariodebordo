# Diário da Isabela

MVP web para registrar mamadas, fraldas e acompanhar cuidados de um recém-nascido.

## Como executar
Abra `index.html` no navegador. Não exige servidor.

## Funcionalidades
- Quatro abas: Início, Mamadas, Histórico e Cuidados.
- Registro de mamadas e fraldas: xixi, cocô ou ambos.
- Cronômetro e lembretes de mamadas (limitados pelo navegador).
- Histórico local e orientações de segurança.

## Privacidade
O repositório é **público** e contém somente código e documentação genérica. Não publique dados reais de saúde, exportações nem informações identificáveis de crianças.
Os registros feitos no aplicativo ficam no armazenamento local do navegador; **não** são enviados ao GitHub nem sincronizados entre dispositivos. Abrir a página por outra origem/navegador pode mostrar um histórico separado.

## Segurança clínica
Aplicativo auxiliar, não substitui acompanhamento pediátrico ou avaliação presencial. Alertas e lembretes não são diagnóstico nem garantem notificação em segundo plano.

## Desenvolvimento
- `index.html`: baseline do MVP no navegador
- `docs/BACKLOG.md`: evolução planejada
- `docs/DECISOES.md`: decisões de produto
