# Decisões do produto

- Repositório GitHub **público** por escolha do responsável.
- Nunca versionar dados pessoais, registros reais de saúde ou backups.
- MVP web com quatro abas: Início, Mamadas, Histórico e Cuidados.
- Ações rápidas prioritárias; detalhes adicionais opcionais.
- Dados operacionais ficam locais no navegador e não são transferidos para o GitHub.
- A versão em testes e seus dados permanecem independentes do repositório.
- Novas funcionalidades devem ser testadas antes de substituir o baseline.
- Publicação pelo GitHub Pages, se desejada, será decisão separada.
